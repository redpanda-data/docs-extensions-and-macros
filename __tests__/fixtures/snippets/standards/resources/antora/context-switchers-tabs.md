# Context Switchers and Tabs

## When to use tabs

```asciidoc
[tabs]
====
Not this one::
+
--
Wrong block.
--
====
```

## Tab syntax

Tabs use the `asciidoctor-tabs` extension:

```asciidoc
[tabs]
====
Tab A::
+
--
Contents of Tab A.
--

Tab B::
+
--
Contents of Tab B.
--
====
```

**Practical example:**

```asciidoc
[tabs]
====
Docker::
+
--
Not this one either.
--
====
```
