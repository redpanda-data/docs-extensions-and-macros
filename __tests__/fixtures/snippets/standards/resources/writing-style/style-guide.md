# Style guide

## Admonitions

Use AsciiDoc admonitions appropriately:

| Type | When to use |
|------|-------------|
| NOTE | A supplement to the documentation with helpful information |
| TIP | A way to make things easier or indicates a best practice |
| CAUTION | A warning that certain behavior is unexpected |

---

## Link validation

| Type | When to use |
|------|-------------|
| WARNING | Not an admonition row: another section's table |
