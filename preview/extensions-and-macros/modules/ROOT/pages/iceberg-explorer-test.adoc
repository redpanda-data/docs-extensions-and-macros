== Default explorer

The simplest usage renders the explorer with built-in sample data:

[iceberg-explorer]
--
--

== With author-supplied defaults

An author can seed the initial config by passing a JSON body. The explorer reads
the `config` key only; other keys are forwarded but ignored.

[iceberg-explorer]
----
{
  "config": "key:mode=schema_id_prefix;value:mode=schema_latest,layout=flat;headers:value_type=string"
}
----

== With a pinned initial config attribute

[iceberg-explorer,config="value:mode=binary",height=420]
