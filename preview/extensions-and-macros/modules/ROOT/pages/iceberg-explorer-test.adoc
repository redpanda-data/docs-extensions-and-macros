= Iceberg Explorer Block
:description: Test to make sure that the iceberg-explorer block emits a hydration mount point.

{description}

The block emits a `div.iceberg-explorer` mount point only. The interactive UI and its translation engine live in the docs-ui bundle, which hydrates the element at runtime, so this page shows the `<noscript>` fallback until a docs-ui build that includes the explorer is in use.

== Empty block

[iceberg-explorer]
--
--

== With an initial config attribute

[iceberg-explorer,config="key:mode=binary;value:mode=binary"]
--
--

== With JSON defaults in the block body

[iceberg-explorer]
----
{
  "config": "value:mode=schema_latest"
}
----
