= Reference values test
:description: Exercises the rpkval, connectval and rpkcmd macros, and the fields and block forms they share with propval: fields, formats, command and component resolution, links, text values, and each placeholder case.

Each line below states what it must render, and what the build log must say
for it. The rpk values come from this component's `rpk-v26.2.2.json` fixture
(trimmed real data from the docs repo's rpk snapshot). The Connect values come
from `connect-4.114.0.json` in the `connect` component, which the showcase
build supplies from `preview/connect-data-lender`.

== rpk flags

* Must read -1: rpkval:[rpk topic create --partitions]
* Must read -p: rpkval:[rpk topic create --partitions,shorthand]
* Must read 30000: rpkval:[rpk cluster self-test start --disk-duration-ms]
* Must read 24h, with `data-source="help"` in the HTML because the flag comes
  from the `ai` plugin's `--help`: rpkval:[rpk ai auditlog list --since]
* Must read stringArray, a global flag with no command:
  rpkval:[rpk --config-opt,type]
* Must read no, and false:
  rpkval:[rpk topic create --partitions,required], and
  rpkval:[rpk topic create --partitions,required,format=raw]
* Must read -1, the `rpk cluster partitions move-cancel` value reached
  through its alias: rpkval:[rpk cluster partitions alter-cancel --node]
* Must read 1m0s in inline code, as Go prints the duration:
  `rpkval:[rpk debug bundle --timeout]`
* Must read -1 again, in the first form of the macro, which is still accepted:
  rpkval:partitions[command=rpk topic create]

== rpk command fields and help text

* Must read `+rpk topic create [TOPICS...] [flags]+`: rpkval:[rpk topic create,usage]
* Must read "status, metadata", the aliases of `rpk cluster info`:
  rpkval:[rpk cluster info,aliases]
* Must read yes, because `--partitions` is not required:
  rpkval:[rpk topic create --partitions,optional]
* Must read the flag's help text, with its backticks shown as written:
  rpkval:[rpk topic create --partitions,description]
* Must show `<unknown description>` and log needs-block, naming
  `+rpkval::[rpk topic create,description]+`:
  rpkval:[rpk topic create,description]
* Must show `<unknown deprecated>` and log dropped-field:
  rpkval:[rpk topic create --partitions,deprecated]

The block form below must render the two paragraphs of the `rpk topic create`
description, with its backticks shown as written:

rpkval::[rpk topic create,description]

The block form below must render each example of `rpk security acl list` as a
paragraph followed by a literal block:

rpkval::[rpk security acl list,examples]

== rpk command links

`rpkcmd:` checks the command against the same rpk data and links the page in
the build: this component has no `rpk` pages, so it links the stand-in pages
of `streaming-ga-lender`, then any other component that has the page.

* Must render `rpk topic create` as code, linked to the `streaming` page:
  rpkcmd:[rpk topic create]
* Must render `rpk topic create --partitions` as code, linked to the same
  page, because the generated pages have no flag anchors:
  rpkcmd:[rpk topic create --partitions]
* Must render `rpk cluster status` as code, linked to the `rpk cluster info`
  page through the alias: rpkcmd:[rpk cluster status]
* Must link the top-level `rpk version` page: rpkcmd:[rpk version]
* Must link the `macro-fixtures-cloud` page, the only component that has one:
  rpkcmd:[rpk cloud login]
* Must link the words "create a topic": rpkcmd:[rpk topic create,text=create a topic]

== rpk command placeholders

Each must render as plain code with no link, and log why.

* unknown-command, suggesting nothing close: rpkcmd:[rpk topic make]
* unknown-flag, suggesting `--partitions`: rpkcmd:[rpk topic create --partition]
* deprecated-command, with the replacement: rpkcmd:[rpk redpanda admin brokers]
* no-page, because no component in this build has a page for it:
  rpkcmd:[rpk debug bundle]
