= Reference values test
:description: Exercises the rpkval, connectval, bloblval, rpkcmd, connect and blobl macros, and the fields and block forms they share with propval: fields, formats, command and component resolution, links, text values, and each placeholder case.

Each line below states what it must render, and what the build log must say
for it. The rpk values come from this component's `rpk-v26.2.2.json` fixture
(trimmed real data from the docs repo's rpk snapshot). The Connect values come
from `connect-4.114.0.json` in the `connect` component, which the showcase
build supplies from `preview/connect-data-lender`, with a few stand-in
component and Bloblang pages for the links to land on.

== rpk flags

* Must read -1: rpkval:[rpk topic create --partitions]
* Must read -p: rpkval:[rpk topic create --partitions,shorthand]
* Must read 30000: rpkval:[rpk cluster self-test start --disk-duration-ms]
* Must read 24h, with `data-source="help"` in the HTML because the flag comes
  from the `ai` plugin's `--help`: rpkval:[rpk ai auditlog list --since]
* Must read stringArray, a global flag with no command:
  rpkval:[rpk --config-opt,type]
* Must read no, and false:
  rpkval:[rpk topic create --partitions,required], and
  rpkval:[rpk topic create --partitions,required,format=raw]
* Must read -1, the `rpk cluster partitions move-cancel` value reached
  through its alias: rpkval:[rpk cluster partitions alter-cancel --node]
* Must read 1m0s in inline code, as Go prints the duration:
  `rpkval:[rpk debug bundle --timeout]`
* Must read -1 again, in the first form of the macro, which is still accepted:
  rpkval:partitions[command=rpk topic create]

=== Docs URLs in rpk descriptions

rpk's help links some pages with docs.redpanda.com URLs. The descriptions
below are that help, as the fixture carries it. The macro maps each URL to a
page as the `url-to-xref` extension does, then links it as it links any other
target in a description.

rpkval::[rpk cluster storage restore start,description]

* You should see "Whole Cluster Restore" in the last sentence as a link to the `streaming` stand-in page, not a URL.
* You should see the sentence period after that link, outside it.

rpkval::[rpk connect test,description]

* You should see "Unit Testing" on the last line as a link to the `connect` stand-in page, not the `/redpanda-connect/` URL.

rpkval::[rpk cluster connections list,description]

* You should see the Admin API URL unchanged, as a plain URL link, and no warning for it in the log.

== rpk command links

the build: this component has no `rpk` pages, so it links the stand-in pages
of `streaming-ga-lender`, then any other component that has the page.

* Must render `rpk topic create` as code, linked to the `streaming` page:
  rpkcmd:[rpk topic create]
* Must render `rpk topic create --partitions` as code, linked to the same
  page, because the generated pages have no flag anchors:
  rpkcmd:[rpk topic create --partitions]
* Must render `rpk cluster status` as code, linked to the `rpk cluster info`
  page through the alias: rpkcmd:[rpk cluster status]
* Must link the top-level `rpk version` page: rpkcmd:[rpk version]
* Must link the `macro-fixtures-cloud` page, the only component that has one:
  rpkcmd:[rpk cloud login]
* Must link the words "create a topic": rpkcmd:[rpk topic create,text=create a topic]

== Aliases and deprecated names

The macros render what you wrote and never fail the build on an alias or a
deprecated name, but the log names what to write instead. `check-reference-values`
reports the same calls, and `--write` rewrites the ones it can.

* rpkcmd:[rpk cluster status]
** You should see `rpk cluster status` as code, linked to the `rpk cluster info` page, and a warning that it is an alias of `rpk cluster info`, naming `+rpkcmd:[rpk cluster info]+`.
* The value is rpkval:[rpk cluster metadata --format].
** You should see `text`, read from `rpk cluster info`, and a warning that `rpk cluster metadata` is an alias, naming `+rpkval:[rpk cluster info --format]+`.
* rpkcmd:[rpk redpanda admin]
** You should see `rpk redpanda admin` as plain code with no link, and a warning that it is deprecated, naming `+rpkcmd:[rpk cluster]+`.
* connect:[inputs/kafka_franz]
** You should see `kafka_franz` as code and the word "input", linked to the `kafka_franz` stand-in page, and a warning that it is deprecated, naming `+connect:[inputs/redpanda]+`.
* connect:[inputs/kafka_franz.regexp_topics]
** You should see `regexp_topics` linked to the `kafka_franz` page with no anchor, and a warning that the field is deprecated and the data names no single replacement.
* blobl:[meta()]
** You should see `meta()` linked to `#meta` on the functions page, and a warning that it is deprecated with no replacement in the data.
