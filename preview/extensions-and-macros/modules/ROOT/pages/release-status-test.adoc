= Release status fixtures
:description: Exercises the enterprise macro's release status gating.

This component is not a prerelease, so it is where the gate should bite.

== An unreleased feature must not be presented as available

enterprise:Preview Unreleased Feature[] is marked `status: unreleased` in the
registry. On this released version it must render as plain text with no
enterprise styling, no tooltip and no link, and the build must say so. The same
mention on the prerelease fixtures renders with an `unreleased` badge.

== A public beta is fine anywhere

enterprise:Preview Beta Feature[] renders with a `beta` badge here and on the
prerelease version alike.

== A shipped feature is unchanged

enterprise:Tiered Storage[] renders as it always has, with no badge.
