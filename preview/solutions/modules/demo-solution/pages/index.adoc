== What you build

A producer that emits player events and a consumer that keeps a leaderboard.

== Architecture

The producer writes to one topic; the consumer reads it with its own consumer group so replay is free.

== Prerequisites

* Docker and Docker Compose
* Go 1.22 or later

== Production considerations

|===
| Concern | What to change

| Durability
| Run three brokers with replication factor 3.

| Security
| Enable TLS and SASL, and create ACLs per service.
|===
